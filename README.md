Idea Forum Web Application

The Idea Forum is a full-stack web platform that allows users to share, discuss, and upvote innovative ideas in real-time. Built using a **Laravel REST API** and a **vue.js frontend**, this project showcases seamless integration, secure authentication, and interactive user experiences.

 Features

-  User Registration & Login (Secure with Laravel Sanctum)
-  Submit, Edit & Delete Ideas
-  Upvote & Downvote Functionality
-  Comment System
- View Ideas in Real-Time
-  API-first Architecture (Frontend & Backend decoupled)


Tech Stack

**Frontend:**
- Vue.Js 
- Bootstrap 

**Backend (API):**
- Laravel 
- Sanctum (for token-based authentication)
- MySQL
- Laravel Resource Controllers & API Routes

**Dev Tools:**
- Git & GitHub
- Postman (API testing)
- VS Code
